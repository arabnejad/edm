# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of EDM.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting A Vulnerability

Please do not report security problems in a public issue.

Use GitHub's private
[vulnerability reporting form](https://github.com/arabnejad/edm/security/advisories/new)
and include:

- the affected EDM version
- steps that reproduce the problem
- the possible impact
- any suggested fix or mitigation

Remove passwords, tokens, private container data, and other secrets from logs
or screenshots before attaching them.

You should receive an initial response within seven days. The report will be
reviewed privately, and a fix and disclosure plan will be discussed with you
when the issue is confirmed.
